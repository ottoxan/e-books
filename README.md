# E-Books Web Application

A web-based **e-book management and browsing system** built with PHP and MySQL.  
This application allows users to **upload, manage, categorize, browse, search, and read e-books** through a web interface with basic authentication.

This project was developed as a **personal project** to practice and demonstrate skills in **backend web development, database design, file handling, and basic system architecture**.

---

## 🚀 Features

- User authentication (login system)
- Browse all available e-books
- View e-books by category / subject
- Search e-books
- Simple and clean user interface
- Backend connected to a MySQL database

---

## 🛠 Tech Stack

- **Backend:** PHP  
- **Frontend:** HTML, CSS, JavaScript  
- **Database:** MySQL  
- **Server:** Apache (XAMPP / LAMP recommended)

---

## 📂 Project Structure (Overview)
/assets → CSS, JavaScript, images
/ebooks → E-book related pages
/login.php → Authentication logic
/allebooks.php → Display all e-books
/ebook.php → E-book viewer page
/localhost.sql → Database schema


---

## ⚙️ How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/ottoxan/e-books.git

2. Move the project folder into your web server directory
(for example: htdocs if using XAMPP).

3. Import the database:
    - Open phpMyAdmin
    - Create a new database (example: ebooks)
    - Import the file localhost.sql

4. Configure database connection:
    - Update database credentials inside the PHP configuration file (if needed).

5. Start Apache & MySQL server.

6. Open in browser:
    - http://localhost/e-books
